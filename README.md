# ai-joke-02 — one-liner about AI coding agents

A program that writes one joke to `/output/entry.txt`:

> My AI agent fixed a one-line bug by adding four dependencies, a config file, and a README. The bug is still there.

The joke is about the most recognisable AI coding-agent habit: a trivial fix
that balloons into dependency bloat while the original bug survives. The
setup promises a fix, the middle escalates (four dependencies, a config file,
a README), and the punchline undercuts it all: the bug is still there.

Run: `MAKEFUN_OUTPUT_DIR=out python3 main.py` (writes `out/entry.txt`).
