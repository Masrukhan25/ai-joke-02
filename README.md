# ai-joke-02 — role-reversal one-liner (v2)

A program that writes one one-liner joke about AI coding agents to `/output/entry.txt` (84 characters).

> My AI agent spent three hours debugging, then asked me what the error message meant.

Angle: role reversal — the supposedly autonomous agent does the debugging for hours, then turns to the human for help. None of the other entries use it.

Run: `MAKEFUN_OUTPUT_DIR=out python3 main.py` (writes `out/entry.txt`).
